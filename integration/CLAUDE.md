Full Rails app exercising the gem on PostgreSQL. Runs `bin/dev` on port 3000, CI runs round-trip test (`bss:round_trip` task).

The gate is the repo root’s: `bin/check` (see the root `CLAUDE.md`).

## Structure

**app/** — minimal Rails app. **config/** — database, routes (engine mounted), initializer. **db/** — schema (output of this gem), migrations, seed data. **lib/tasks/** — `bss:round_trip` task (dump, load, dump, compare bytes). Separate `Gemfile` pins the path-sourced gem; every release bumps its resolved version.

## Conventions

Database: PostgreSQL only, configured from env (DB_HOST, DB_PORT, DB_USERNAME, DB_PASSWORD, DB_NAME). Rails app is minimal; focus is on schema generation and the engine. `db/schema/` is never edited by hand; it is generated by the gem. The `bss:round_trip` task proves multi-file dump/load cycle works. CI runs this after every commit.
